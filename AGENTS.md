# Instruções para agentes

## Contexto do projeto

Este repositório é destinado à implementação educacional de um clone do TabNews, acompanhando o projeto do curso.dev.

## Convenções de trabalho

- Siga a arquitetura existente e as convenções do Next.js App Router.
- Antes de alterar código, consulte os arquivos relacionados e reutilize os padrões já adotados no projeto.
- Faça mudanças focadas, preserve o comportamento existente e evite alterações fora do escopo solicitado.
- Execute as verificações disponíveis que forem relevantes para cada mudança.
